```

┌─ Background: Gradient ──────────────┐
│ Shadow: 0 8px 25px rgba(..., 0.3)  │
│ Transform: translateY(0)            │
└─────────────────────────────────────┘

┌─ Background: Gradient (unchanged) ──┐
│ Shadow: 0 12px 35px rgba(..., 0.5) │

└─────────────────────────────────────┘
```

## Spacing & Dimensions

### Card Padding
- Outer: 35px
- Inner: 30px
- Gap between cards: 25px

### Form Layout
- Grid gap: 20px
- Row gap: 25px between form rows
- Input padding: 14px vertical, 16px horizontal

### Table
- Header padding: 18px vertical, 16px horizontal
- Body padding: 16px vertical, 16px horizontal
- Row gap: 1px border

### Button Sizes
- Padding: 13-16px vertical, 28-30px horizontal
- Font-size: 14-16px
- Border-radius: 12px

## Animation Timings

### Fast Animations
- Input focus: 0.3s
- Row hover: 0.3s

### Medium Animations
- Button hover: 0.3-0.4s
- Color transitions: 0.3s

### Smooth Animations
- Tab switch: 0.4s cubic-bezier(0.34, 1.56, 0.64, 1)
- Form open/close: 0.3s

## Accessibility Features

### Color Contrast
- White on Purple: 12.5:1 ✅ WCAG AAA
- Dark on Green: 8.2:1 ✅ WCAG AA
- Dark on Yellow: 6.5:1 ✅ WCAG AA
- White on Orange: 7.1:1 ✅ WCAG AA

### Font Readability
- Minimum size: 13px
- Maximum size: 26px
- Optimal range: 14-16px for body
- Font-weight: 500-800 for clarity

### Focus States
- All interactive elements have visible focus state
- Border or color change on focus
- No elements rely solely on color
