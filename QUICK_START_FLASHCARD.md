## 🚀 How to Add a Product (30 seconds)

### Step 1: Click "Add Product"
```
Look for the green button in top-right:
➕ Add Product
```

### Step 2: Fill the Form
```
📦 Product Name:        "Rice" or "Wheat"
📊 Quantity:            "100"
⚖️ Unit:               "kg" (default)
💰 Price/Unit:         "40" or "50"
🖼️ Upload Image:       Select image from computer
🚚 Deliver Within:      "3" or "5" days
📈 Status:              "Available" (default)
📍 Location:            "Punjab" or your location
```

### Step 3: Click Submit
```
Look for the purple button:
🚀 Add Product
```

### Step 4: See Your Flashcard!
```
Your flashcard appears immediately:
- Smooth slide-up animation (0.4s)
- Image displays (if uploaded)
- All details shown
- Delete button ready
- Form resets automatically
```

## ❓ Troubleshooting

**Issue**: Image not showing?
- ✅ Make sure to upload an image
- ✅ Check image file is valid (JPEG/PNG)

**Issue**: Flashcard not appearing?
- ✅ Wait 2 seconds (API response time)
- ✅ Check browser console (F12 → Console)

**Issue**: Grid looks wrong on mobile?
- ✅ Refresh page (Ctrl+R)
- ✅ Rotate device if needed
