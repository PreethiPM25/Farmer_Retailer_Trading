## 🛠️ Quick Reference

### Commands
```bash
# Backend
cd backend
mvn spring-boot:run

# Frontend
cd frontend
npm install
npm start

# Build
mvn clean package        # Backend
npm run build           # Frontend
```

### URLs
- Frontend: http://localhost:3000
- Backend: http://localhost:8080
- H2 Console: http://localhost:8080/h2-console

### Credentials
- Admin: admin@agripulse.com / Admin@123

### Ports
- Backend: 8080
- Frontend: 3000
