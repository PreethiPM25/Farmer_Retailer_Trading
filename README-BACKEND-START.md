# Backend Server Start Instructions

## Quick Start
1. Open Command Prompt as Administrator
2. Navigate to: `cd c:\agri-pulse\backend`
3. Run: `mvn spring-boot:run`

## Alternative Method
1. Open IntelliJ IDEA or Eclipse
2. Import the backend project
3. Run AgriPulseApplication.java main method

## Verify Server is Running
- Open browser: http://localhost:8080
- Should see Whitelabel Error Page (this is normal)
- Backend is ready when you see Spring Boot startup logs

## If Maven not found:
1. Install Maven from https://maven.apache.org/download.cgi
2. Add Maven to PATH environment variable
3. Restart Command Prompt

## Registration will work once backend is running on port 8080
