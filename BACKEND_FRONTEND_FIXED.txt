⚙️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════════

If Frontend shows "Cannot connect to server":
   1. Verify backend is running: netstat -ano | findstr "8080"
   2. Check CORS configuration in CorsConfig.java
   3. Clear browser cache (Ctrl+Shift+Delete)
   4. Reload page (Ctrl+R)
   5. Check browser console for specific error

If Backend won't start:
   1. Check port 8080 is not in use: netstat -ano | findstr "8080"
   2. Verify Java is installed: java -version
   3. Check database file: agripulse_db.mv.db (delete if corrupted)
   4. Review error logs in terminal

If Database connection fails:
   1. Delete corrupted DB file: agripulse_db.mv.db
   2. Restart backend (new DB will be created)
   3. Check H2 console: http://localhost:8080/h2-console
   4. Verify connection string in application.properties
